# Sudhir Kumar | Portfolio

A modern, high-performance personal portfolio website built with **React 19**, **Tailwind CSS v4**, and **Vite**.

## 🚀 About

I am **Sudhir Kumar**, a B.Tech CSE 3rd Year undergraduate from Bihar, India. I specialize in Full Stack Web Development (React, Node.js, Express), Distributed Network & Socket Applications (QuickDrop), and Object-Oriented Java Systems (Trading Simulator, Academic Record Management).

## 🛠️ Tech Stack

- **Frontend:** React 19, Tailwind CSS v4, HTML5, CSS3, Modern Web APIs
- **Backend & Systems:** Node.js, Express.js, Socket.IO, Java (OOP, Collections, File I/O), Python
- **Tooling & Workflow:** Vite, Electron, Git, GitHub, VS Code, Postman

## ✨ Key Features

- **Sleek 2026 UI/UX:** Ambient glowing gradients, glassmorphism headers, subtle micro-interactions, and dark mode aesthetic.
- **Fully Responsive Mobile Menu:** Collapsible mobile navigation drawer with quick links and CV download.
- **Hero Section:** Live availability status badge, high-impact typography, social links, and floating achievement chips.
- **Categorized Technical Skills:** Organized by Languages, Frontend, Backend & Systems, and Developer Tools.
- **Education & Experience Timeline:** Documenting B.Tech CSE (2022–2026) and CodeAlpha Software Engineering Internship.
- **Interactive Project Showcase:** Filter projects by category (*All*, *Full Stack*, *Java & Systems*, *AI & Python*) with architectural highlights and repository links.
- **Interactive Contact:** 1-click clipboard email copier with feedback confirmation, direct email links, and prefilled message form.
- **Instant Resume Download:** Direct download link for `Sudhir_Kumar_resume.pdf`.
